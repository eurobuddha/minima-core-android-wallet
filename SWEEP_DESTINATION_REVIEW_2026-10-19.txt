Behavior
Typed and scanned destinations must decode with a valid Minima checksum to exactly
32 bytes and round-trip to the same canonical Mx encoding (case-insensitive).
Raw 0x, malformed encodings, wrong checksums, wrong decoded lengths, decoder aliases
and trailing payload are rejected before review. No generic Send policy was changed.
The existing review now opens a separate final dialog showing the complete address.
Its signing button remains disabled until the user enters the same full Mx address.
Execution independently rechecks both validity and the second entry before accessing
the vault. Standalone's explicit retry returns through review and confirmation too.
Integrated pending transaction replay retains the existing exact-byte behavior.
Four host languages updated; standalone retains its existing English UI.

Validation does NOT establish recipient ownership, script spendability or historical
use. A newly generated address need not appear on-chain. The final prompt explicitly
states this limitation and asks the user to compare against the receiving wallet.
